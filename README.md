# homebrew-tap

Homebrew casks for my apps.

## [bradipo](https://github.com/marcoieni/bradipo)

A menu bar break reminder for macOS 27.2.1 or later.

```sh
brew install --cask marcoieni/tap/bradipo
```

bradipo isn't notarized by Apple. The cask removes the quarantine that Homebrew adds, so macOS opens bradipo without Gatekeeper's check. Install it only if you trust this repository and bradipo's.

bradipo's release workflow updates the cask here.
