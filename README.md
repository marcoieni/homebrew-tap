# homebrew-tap

Homebrew casks for my apps.

## [bradipo](https://github.com/marcoieni/bradipo)

A menu bar break reminder for macOS 27.2.1 or later.

```sh
brew install --cask marcoieni/tap/bradipo
```

bradipo isn't notarized by Apple, so [allow it to open](https://github.com/marcoieni/bradipo#allow-bradipo-to-open) after you install or upgrade it. Its release workflow updates the cask here.
